## 运行

```bash
pip install matplotlib
OUT=./out python3 f3.py        # 输出到 ./out
python3 f3.py                  # 不设 OUT 则输出到当前目录
for f in f1 f2 f3 f4 f5 f6 f7 f8 f9; do OUT=./out python3 $f.py; done
```

无其它依赖。字体用 DejaVu Sans（matplotlib 自带），因此**图内文字全部是英文**——
matplotlib 默认不带中文字体，早期尝试出过豆腐块。要出中文版需先注册中文字体，
Noto Sans CJK 是 .ttc 格式，matplotlib 处理起来容易反复，不建议走这条路。

## 给设计的说明

**优先用 SVG。** 已设 `svg.fonttype = 'none'`，SVG 里文字保留为 `<text>` 对象而不是转成路径，
导入 Figma / Illustrator / draw.io 后可以直接改字、换字体、调间距。

**坐标系统。** 画布单位 = 1/10 英寸，脚本里的 `W, H` 即为宽高（如 `W, H = 178.0, 104.0`
表示 17.8 × 10.4 英寸），`newfig()` 按 160 dpi 输出。原点在左下角，y 轴向上——
和 Figma 的 y 轴向下相反，读脚本坐标时注意。

**调色板在 `lib.py` 顶部的 `P` 与 `BG` 两个字典里**，按"层/角色"命名而非按颜色命名：

| 键 | 含义 | 描边 | 浅底 |
|---|---|---|---|
| `ing` | 接入层 | `#0f766e` | `#eef7f5` |
| `sto` | 存储层 | `#1d4ed8` | `#eef2fd` |
| `pro` | 加工层 | `#6d28d9` | `#f3eefc` |
| `svc` | 服务层 | `#b45309` | `#fdf4e7` |
| `pre` | 展现层 | `#be123c` | `#fdeef1` |
| `ops` | 管理运维 | `#334155` | `#f1f3f6` |
| `ext` | 系统外 | `#6b7280` | `#f4f4f5` |
| `ok` / `bad` | 正常 / 风险 | `#15803d` / `#b91c1c` | — |

**重画时请守住的三条视觉约定**，它们承载语义不只是好看：

1. **虚线框 = 系统边界之外或后续阶段**（图 3-1 的 L0 整层、移动应用；图 3-2 的入向源系统）。
2. **橙色虚线箭头 = 查询路径**，与深灰实线的数据流是两回事。图 3-1 里它刻意绕过加工层，
   表示"加工层不在任何一次用户查询的链路上"——这条画错会让性能责任和故障边界失去依据。
3. **红色 = 关键风险或不可协商的约束**（图 12-1 的 ST-01、RS-01；图 11-1 的双主风险）。

## v0.3 的改动

四张图随详细设计第一轮讨论的结论更新，其余五张未受影响。

| 图 | 改动 |
|---|---|
| `f1.py` 图 3-1 | 画布加高至 14.1 英寸。L4 由两行扩为三行，增补 Record Search Service、Alert Rules & Evaluation、MCP Server（虚线，可选），Subscription & Delivery 改为 Delivery Service（报表与告警）；L5 移动端由虚线"later phase"改为本期交付并改标 IF-40，Dashboards 补足为 20（v0.2 欠账）；L6 增补 Classification & Discovery 并将控制台扩至 M-11；L2 注明 PostGIS 为扩展而非第二个数据库产品；L0 与 L1 补 AI 结果回流与多版本 schema 归一化 |
| `f2.py` 图 3-2 | 画布加高至 12.8 英寸。入向补 IF-07（AI 推断结果回流）；出向补 IF-37/38/39（AI 包取数与叙述生成）与 IF-41（HudHud 本地地图服务）；移动端转为实线并改走 IF-40（经 DMZ 反向代理）；IF-34 改为报表与告警的统一投递，通道为邮件与短信网关 |
| `f6.py` 图 7-1 | 查询路径中的 Query API 改为 Query API / Record Search，Identity & Authz 注明字段与部门两级下推，并补一行记录检索的约束说明 |
| `f7.py` 图 9-1 | 副标题十改十一；M-06 改为字段级可见性矩阵加部门行过滤（已启用）；原"行级安全预留未启用"的设计说明作废，该卡位改为 M-11 Classification & Discovery |

**画布比例变了的两张图**（f1、f2）在嵌入 Word 时需同步调整显示高度，否则会被拉伸。
HLD v0.3 的文档中已按新比例设置。

## 与文档的同步

嵌入 HLD 文档的 PNG 与本目录的输出保持一致。若只改脚本而不重新嵌入，
文档里的图会与设计文本不符——v0.2 就出过这个问题（脚本里 Dashboards 已是 20，
文档里嵌的图仍是 12）。改图之后请重新生成并替换文档中的图片。
