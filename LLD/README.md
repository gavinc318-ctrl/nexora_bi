# OSS911 BI 与数据仓库 — 详细设计（LLD）

麦加 911 运营中心 · 商业智能与数据仓库子系统 · 沙特 MOI

本目录是详细设计的 Markdown 版本，供 AI 与开发工具读取。内容由 `.docx` / `.xlsx`
原件转换而来，**文字未作改写**；原件在上级目录，两者不一致时以原件为准。

**不要直接编辑本目录下的 `.md`。** 它们是派生物——改原件后跑 `../tools/run.py`
重新生成。手改会在下次生成时被覆盖，而且会让两边悄悄分叉。

## 先读这三条

1. **服务层是唯一出口。** 展现层、移动端、AI 包、ESB、外部系统一律经服务层，
   任何组件不得直连数据库。绕过服务层的查询既不受权限约束，也不进审计。
2. **raw 层不做任何解释。** 源端原样落地，版本判断、列对应、业务语义一律在
   staging 的 dbt 模型中完成。解释错了重跑 dbt，不必回源端重拉数据。
3. **口径唯一。** 同一指标编码在门户、报表、移动端、对外接口解析成同一段 SQL。
   前端不做二次聚合——算第二遍就有了第二个实现，两者迟早不一致。
