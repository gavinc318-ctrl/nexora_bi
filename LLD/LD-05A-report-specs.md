# 报表与仪表板规格册

## 说明

| LD-05A  报表与仪表板规格册 |  |
| --- | --- |
| 本册的性质：样板与骨架，不是定稿。 |   |
| 报表与仪表板的具体内容须在合同签订后与客户逐张对齐——RFP 1.6.2.9、1.6.2.20、1.6.2.28 与 1.6.2.30 均规定报表数量、类型、查询参数与图表类型「与 MOI 通过工作坊共同确定」。因此本册现阶段的作用是：定义每张报表的规格要填哪些字段、把已由设计确定的部分填上、并为逐张对齐提供登记表。 |   |
| 未确定的格子留空，不填占位文字。空白代表「尚未与客户对齐」，是一条真实的状态信息；填上看似合理的内容会掩盖它。 |   |
| 怎么用 |   |
| 一、「规格字段定义」页说明每一列填什么、为什么需要它、以及填错的后果。开始对齐前先读这一页。 |   |
| 二、「报表规格（40）」与「仪表板规格（20）」是主表。绿色底纹的行是已填满的样板，示范规格该写到什么颗粒度。 |   |
| 三、每与客户对齐一张，在「对齐登记」页记一行，并把该行的「规格状态」改为「已对齐」。 |   |
| 四、工作坊新增的报表从 R-41 起编号，仪表板从 D-21 起，以便区分基线与增补（沿用 HD-05 的编号规则）。 |   |
| 样板选了哪几张，为什么 |   |
| R-01 每日话务量汇总——最简单的一类，示范基本字段怎么填。 |   |
| R-14 平均响应时长——口径最容易出分歧的一张。LD-03 已把「平均到场时长」拆成三个定义，这张报表示范口径分歧如何在规格里写清楚，而不是留到验收时争论。 |   |
| R-22 班次覆盖与人力缺口分析——本轮决策改写了定义的一张，示范改写后的规格怎么写。 |   |
| R-38 数据质量与对账报表——数据来自 meta 与 audit 而非业务事实表，示范这一类的写法。 |   |
| D-05 当日运行概览——未封账数据的标注要求最吃紧的一个。 |   |
| D-11 热点与聚集区分析——涉及地图嵌入与降级行为。 |   |
| 本轮设计决策造成的清单调整 |   |

## 规格字段定义

| 列 | 字段 | 填什么 | 为什么需要它 · 填错的后果 |
| --- | --- | --- | --- |
| A | 编号 | R-xx 或 D-xx。一经分配不再变更。 | 编号是与客户对齐、变更登记、测试用例三处的共同锚点。改编号会让三处对不上。 |
| B | 主题域 | 五个之一：接警话务、警情处置、资源与勤务、绩效与质量、系统运行。 | 决定报表在门户目录中的位置，也决定谁会看到它。 |
| C | 报表名称 | 中文名称，与客户确认后的用词为准。 | 客户口中的叫法与我方的叫法不一致时，验收会出现「这张报表在哪」的争论。 |
| D | 英文名称 | 英文名称。报表按语言各出一份（LD-05 3.5），两份各有其标题。 | 不是中文名的直译，而是英文版报表的正式标题。 |
| E | 读者与用途 | 谁看、用来做什么决定。一两句话。 | 这一栏决定了后面所有栏的取舍。写不出用途的报表，通常是没有人真正需要它。 |
| F | 指标编码 | 引用 metrics.yaml 中的编码，不写指标名称。 | 编码是唯一事实来源。写名称会在口径变更时失去追溯——名称可以一样而定义已经变了。 |
| G | 维度 | 可用于分组与下钻的维度。 | 决定语义层是否接受该组合。粒度不匹配的组合由服务层拒绝（LD-04 3.1），不做静默降级。 |
| H | 参数（必填 · 可选 · 默认） | 分三类列出。默认值须按角色给出，使报表打开即有数据。 | 默认值不得跨越权限边界——调度员的默认辖区是其本部门（LD-05 5.1）。 |
| I | 时间粒度 | 日、周、月、季、年；话务类可到小时。 | 与指标的 grain 必须一致，否则算出来的是另一个数。 |
| J | 数据新鲜度 | 指示性 · 当日临时值 · 封账值 · 监控数据 · 审计数据。 | 这是口径承诺不是技术细节。标为封账值的数字在重复运行时必须一致。 |
| K | 行级权限 | 是否按部门过滤；接警员与管理员不受限。 | 漏填等于默认不过滤。部门映射不上时拒绝放行而非静默返回空（LD-07 2.3）。 |
| L | 敏感字段 | 本报表是否含报警人电话、精确位置、姓名等。 | 决定字段级可见性矩阵的默认取值与脱敏规则，也决定这张报表能不能进培训环境。 |
| M | 图表与呈现 | 图表类型与选择理由，或表格。 | RFP 1.6.2.30 要求图表类型与 MOI 共同确定。理由写下来，对齐时才谈得下去。 |
| N | 版式（屏幕 · 打印） | 屏幕布局要点与打印纸张、方向、跨页规则。 | 打印版式是独立的一套，不是屏幕版的缩放。表格跨页须重复表头。 |
| O | 导出与订阅 | 支持的导出格式；是否可订阅、默认订阅周期。 | 订阅按订阅者本人权限渲染（LD-04 5.3）。这一栏漏填会让订阅默认按配置者权限，属越权。 |
| P | 频率 | 每日、每周、每月、按需。 | 与订阅周期配合。频率高而计算重的报表须评估是否预聚合。 |
| Q | 对应 RFP | 条款号。 | 追溯矩阵的输入。无条款对应的报表须说明来源，否则验收时无从主张它算在四十张内。 |
| R | 是否复刻现有 | 是 / 否。 | 对应 RFP 1.6.2.18 与 1.6.2.28。本册按「复刻项包含在四十张之内」编制，此解读待 MOI 确认（T-18）。 |
| S | 依赖未决 | 依赖哪一条 IR 或 T 项；不依赖则留空。 | 让「这张报表现在做不了」有据可查，而不是到实施期才发现缺数据源。 |
| T | 规格状态 | 样板 · 待与客户对齐 · 已对齐 · 待替换 · 待客户确认数据源。 | 说明页的统计公式按此列计数。状态值须用这五个词，不要自创。 |
